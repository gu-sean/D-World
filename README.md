develop을 받고 `backend/.env.supabase`(팀에서 따로 받음)를 둔 뒤 `cd backend && npm install && npm run demo:supabase`

- id: 01099999999
- 비번: 1234567890

### 에뮬레이터 점검 (Android, 시험 계정)
점검 환경: 에뮬레이터(RAM 4GB) + 시연 DB 복원본 + 개발 서버(Metro), AI 서버 없음

**정상 동작 확인**
- 로그인, 홈(오늘 미션 표시)
- 미션 관리 목록, **미션 직접 만들기**(저장 후 DB 확인)
- 목표 목록, **AI 계획 만들기·수락**(미션 23개 생성)
- 리포트(주간·분야별·계획 조정 제안), 연속 기록
- 마이: 경험치·포인트·펫, 업적, 포인트 내역
- **상점 교환**(포인트 차감·보유 수량 증가)
- 챌린지 목록, **챌린지 참여**(상태·DB 확인)
- 알림함, 공지사항, 문의·신고 목록, 구독("준비 중" 안내)

### API로 확인한 것 (앱 화면 없이)
- 영상 인증 경로 전체: 업로드(MinIO) → 제출 → AI 다운로드·분석 → 콜백 → 판정 저장
  (사람이 없는 합성 영상이라 인식 정확도는 검증하지 못함)
- 관리자 웹이 읽는 응답 필드: 목 응답과 실제 응답 비교 후 계약 테스트 추가
