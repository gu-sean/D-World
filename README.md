# D-World

## 프로젝트 소개

D-World는 사용자가 세운 목표를 AI가 매일 할 수 있는 세부 미션으로 나눠 주고, 미션 수행을 인증하고 보상하는 **목표 관리 앱**입니다. 분야별로 확장하는 구조이며, 지금은 운동 분야를 지원합니다.

- **AI 계획:** 목표 문장·기간·현재 수준과 사용자 정보·최근 기록을 바탕으로 주차별로 점점 올라가는 세부 미션을 만듭니다.
- **수행 인증:** 운동은 AI가 영상으로 횟수·자세를, 러닝은 GPS·걸음·흔들림으로 거리를 판정합니다.
- **보상:** 미션을 완료하면 포인트와 펫 경험치를 받고, 펫 키우기·연속 기록·업적·챌린지로 이어집니다.

## 주요 기능

### 🎯 AI 목표 계획
- 목표 제목·설명·기간·현재 수준을 해석해 **주차별 점진 계획** 생성 (Gemini)
- 계획이 잘못된 형식으로 오면 서버가 검증하고, 규칙 기반 점진 계획으로 대체
- 수행 결과가 나쁘면 **재조정 에이전트 체인**이 남은 계획을 다시 짜서 제안
  - 수행 분석 → 계획 조정 → 안전 검토 → (필요하면) 재수정

### 🧭 난이도·목표 추천
- 회원가입 때 받은 나이·키·몸무게와 최근 28일 수행 기록으로 난이도와 시작 목표를 추천
- **프로필 분석 → 수행 기록 분석 → 안전 검토** 3단계 에이전트가 순서대로 판단
- 날씨(기상청 실제 데이터)와 시간대에 맞는 미션 추천, 추천 이유를 보고 최대 3개 선택

### 🎥 운동 영상 인증
- 앱에서 촬영(최대 10분, 압축) 후 업로드
- MediaPipe 관절 추출 + 규칙 기반 판정: 푸쉬업·스쿼트·런지·플랭크·버피
- 자동 승인·반려·관리자 검수, 같은 영상 재제출 차단

### 🏃 러닝 인증
- 실시간 거리·페이스·시간·칼로리·케이던스, 네이버 지도 위 경로 표시
- 30초 구간마다 속도·걸음·흔들림을 보고 **탈것 구간을 자동으로 제외**
- 서버가 같은 규칙으로 다시 계산해 자동 승인·반려

### 🐾 펫 키우기와 보상
- 세부 미션 하나당 **30P + 펫 경험치 30**
- 알 → 아기 → 성체로 자라는 펫, 도감 21종
- 연속 기록(스트릭), 업적·배지, 포인트 상점, 공개 챌린지와 랭킹

### 📊 리포트
- 주간·월간 달성률, 월별 기록 달력, AI 리포트

### 🛠 관리자 웹
- 대시보드, 회원 관리, 인증 검수(AI 판정 보류·이의 신청), 문의·신고 처리
- 미션 틀·챌린지·업적·펫 종류·상점 관리와 이미지 업로드
- 공지·약관·정책 등 운영 콘텐츠, 감사 로그

## 시스템 구성

| 구성 | 기술 | 역할 |
|---|---|---|
| 모바일 앱 | React Native 0.86 (Android) | 사용자 앱 |
| 관리자 웹 | React 19, Vite, Ant Design | 운영·검수 |
| 백엔드 | NestJS (Node.js) | 앱 API `/api/v1`, 관리자 API `/admin/v1`, AI 콜백 `/internal/v1`, 정기 작업 |
| AI 서버 | FastAPI, MediaPipe, Gemini | 운동 영상 판정, 목표 계획·난이도 추천·재조정·리포트 |
| 데이터베이스 | PostgreSQL 17 (Supabase) | 모든 표에 행 수준 보안(RLS), 원장·정책 버전 수정 차단 |
| 파일 저장소 | Cloudflare R2 (개발: MinIO) | 인증 영상, 펫·배지 이미지 |
| 외부 연동 | FCM, 기상청 API허브, 네이버 지도 | 푸시 알림, 날씨, 러닝 지도 |

## 폴더 구조

```
mobile/      React Native 앱
admin-web/   관리자 웹
backend/     NestJS API 서버
ai/          FastAPI 비전·LLM 서버
db/          PostgreSQL 마이그레이션·시드
docs/        설계 문서
image/       펫 이미지 원본
```

## 실행 방법

### 1. 백엔드 (공유 DB로 바로 띄우기)
```bash
cd backend && npm install && npm run demo:supabase
```

### 2. AI 서버
```bash
cd ai && python -m venv .venv && .venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

### 3. 관리자 웹
```bash
cd admin-web && npm install && npm run dev   # http://localhost:5173
```

### 4. 모바일
```bash
cd mobile && npm install && cp .env.example .env
npm start            # Metro
npm run android      # 다른 터미널에서, 에뮬레이터·기기 연결 후
```
