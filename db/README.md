# D-World DB

PostgreSQL 14+, 마이그레이션은 번호 순서대로 적용

```
db/
  migrations/   001~015
  tests/        마이그레이션별 smoke SQL (롤백)
  seeds/dev/    개발용 시드
  scripts/      verify.sh
```

## 실행

```sh
for f in db/migrations/*.sql; do psql -v ON_ERROR_STOP=1 -d d_world -f "$f"; done
for f in db/tests/*.sql;      do psql -v ON_ERROR_STOP=1 -d d_world -f "$f"; done   # 시드 전에 실행
psql -v ON_ERROR_STOP=1 -d d_world -v admin_password_hash='<hash>' -f db/seeds/dev/001_dev_reference.sql
```

`sh db/scripts/verify.sh`: 임시 DB에 마이그레이션·smoke·시드를 적용하고 삭제, 접속 정보는 `PG*` 환경 변수

## 앱이 지켜야 할 규칙

DB가 강제하지 않는 것만 정리

**트랜잭션**
- 포인트: `point_wallets` 행 잠금 → 한도 집계·원장·잔액·미회수액을 한 트랜잭션으로 (원장은 수정·삭제 불가)
- 인증 승인: 제출 번호 배정, 현재 판정 교체, 미션 완료, 보상 지급을 한 트랜잭션으로
- 판정 번복: 스트릭·마일스톤·챌린지 재계산을 포인트·XP·배지 회수와 같은 트랜잭션으로
- XP: 원장·캐시 잔액·레벨·진화 이력을 함께 갱신, 펫 XP 수령자는 수행 시작 때 고정(대표 펫이 없으면 `pending_pet_experience`)
- 챌린지 지급: 참가자 한 명당 한 트랜잭션, 중복은 `challenge_reward_grants`와 원장 멱등 키가 막고 실패는 `challenge_reward_payment_attempts`로 재시도
- 상점: 지갑 잠금 → `spend` 원장 → `shop_orders` → `user_inventory_events`, 환불은 미사용 수량만
- AI 제안 수락과 미션 생성, 재생성의 취소와 생성은 각각 한 트랜잭션

**멱등성**
- AI 판정·분석 결과는 `ingest_key` 필수
- 관리자 변경 요청은 `admin_idempotency_keys`에 `in_progress`로 먼저 삽입, 같은 키에 `request_hash`가 같으면 저장된 응답 재생, 다르면 오류

**R2**
- 서버가 업로드 URL을 발급하고 업로드 후 존재·크기·형식을 확인해 `uploaded`로 변경
- 탈퇴: R2 정리 확인 → `upload_status='deleted'` → `users` 삭제 (미정리 파일은 트리거가 차단)

**탈퇴 순서**
- 비공개 미션 원형을 먼저 삭제, 실행 미션이 참조하는 원형은 선정리
- 개인 펫 원장·참조를 정리한 뒤 삭제, 공용 펫 정책·단계 이미지는 보존
- 확정 챌린지 순위의 표시명 익명화는 DB가 처리

**서버 작업**
- 단계 종료일 이후 필수 미션 완료 시 목표 자동 완료
- 예약 공지 게시, 회원별 알림 생성(`fanout_completed_at` 기록), 푸시 발송·재시도
- 푸시는 수신 설정이 꺼졌거나 활성 기기가 없으면 `skipped`, 마케팅 공지는 동의 회원만
- 문자 발송 간격, 인증 만료 3분, 비밀번호 5회 실패 후 5분 제한, 세션 회전, 약관 재동의
- 업적 조건 변경·신규 공개 후 과거 활동 백필, 스트릭 업적은 `streak_milestone_awards`의 포인트 지급 재사용
- 재조정 수락 시 단계·미션 변경과 `accepted_plan_json` 저장을 한 트랜잭션으로, 리포트·재조정은 `superseded_at` 기록 후 `generation_no`를 올려 재생성
- 문의·신고: 신고자 정보는 대상자·결과 안내에 노출하지 않음, 콘텐츠 조치는 기존 게시 상태 변경으로 실행하고 티켓에는 `content_action`만 기록

## 운영 전 필요한 값

- 사용자·펫 레벨 정책, 펫 단계 버전
- 스트릭 7·30·100일 보상
- 미션 보상표(카테고리 × 난이도)
- 인증 판정 기준(카테고리 × 방식)
- 월간 포인트 한도(004는 100,000P로 시작)
- 약관·개인정보 문서

004 적용 전 미션·템플릿은 보상 0P, 운영 데이터가 있으면 별도 보정 필요

없는 것: 펫 종류·단계 이미지, 배지 이미지·업적 정의, 공식 미션 템플릿, 상점 상품
