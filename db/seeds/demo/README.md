## 실행

```bash
# 해시는 backend의 argon2로 만든다 (argon2id)
psql "$DATABASE_URL" -v admin_password_hash='<해시>' -v user_password_hash='<해시>' \
  -f db/seeds/demo/001_demo_week.sql
```

- 트랜잭션 안에서만 `session_replication_role = replica`로 트리거(FK 포함)를 끈다. CHECK·UNIQUE는 그대로 동작한다.
- 성체 펫 경험치 450은 일주일 한도로는 쌓이지 않아 `seed_grant` 보정 지급으로 채웠다.
- 영상 파일은 메타데이터만 있어 R2/MinIO에 객체가 없으면 관리자 웹에서 재생되지 않는다.
